# 세트 도감 자료 출처 및 검증

- 수집일: 2026-10-28
- 원본 수치: https://github.com/blizzhackers/d2data — json/sets.json, json/setitems.json 및 기존 장비·옵션 테이블.
- 현대 한글 명칭 대조: https://github.com/SeonEngineer/D2R/blob/main/item-names.json
- 이미지: https://classic.battle.net/diablo2exp/items/sets/sets7.shtml 의 공식 분류 페이지 링크에서 수집. 각 구성품 imageSource 및 public/sets/manifest.json에 원본 URL 보존.
- 저장소 MIT 고지는 source-license.txt에 보존. 게임 텍스트와 이미지의 권리는 Blizzard Entertainment에 있으며 소프트웨어 라이선스가 게임 아트 이용 허락을 대신하지 않음. 광고 사이트의 공개 이미지 이용 범위는 별도 확인 필요.

## 범위

spawnable=1인 구성품이 있는 34세트, 135개 구성 아이템을 반영. 비활성 Warlord's Glory 5개는 제외. 현재 127개 구성품에 이미지 연결. Bane's Garments 3개 및 Horazon's Splendor 5개는 이미지·현대 한글 명칭을 확보하지 못해 영문 이름과 이미지 미확보로 표시.

## 효과 해석

구성품 기본 옵션 prop, 구성품 추가 옵션 aprop, 세트 공통 개수별 효과 PCode, 전체 착용 추가 효과 FCode를 분리. 개수별 효과는 누적되며 전체 추가 효과와 함께 적용됨. 특정 효과가 두 테이블에 반복되는 경우 임의로 중복 제거하지 않음(별도 추가량일 수 있음).

add func=2의 aprop1~5는 해당 아이템을 포함한 2~6개 착용 조건. add func=1인 시버브의 수호는 공식 가이드와 대조해 시버브의 우상(마나), 시버브의 곤봉(독 저항)을 함께 착용하는 조건으로 표시. 구성 아이템에 더해지는 효과와 세트 공통 효과를 섞지 않음.

캐릭터 레벨 비례 옵션, 내부 독 피해율과 지속시간, 시각 효과 상태를 구분. 원본 스킬명은 일부 영문 유지. 기본 피해·방어력은 옵션 적용 전 수치로 표시하고 최종 계산값으로 제시하지 않음. 전체 착용 레벨은 구성품 요구 레벨의 최댓값. 주요 직업 UIClass는 추천 분류이며 전 구성품의 직업 제한으로 표현하지 않음.

원본에서 시즌 조건이 있는 구성품은 상세에 보존. 패치·확장팩·시즌별 차이가 있을 수 있음. 전 항목을 게임 내 툴팁과 개별 대조한 것은 아님.

## 자동 검증

세트·구성품 ID 중복, 34/135개 수량, 127개 이미지 연결, 착용 개수 범위, 탈 라샤 5개/최대 요구 레벨 71, 시버브의 수호의 특정 조합 2개, 트래그울 전체 착용 변신 효과를 검사.
