# ITEM-34-B — Runeword Results

## Eternity (ID 58)

The existing row, five socket count, rune order, and 3.3 root options remain. Its RotW 3.4 online Ladder/Offline variant uses the official broad equipment label “melee weapons and missile weapons,” adds 30% IAS, updates enhanced damage to 300–390%, adds +3–297 maximum damage per character level, and replaces the old Revive charges with level 5 Revive O-skill.

The filter catalog recognizes the broad equipment label without claiming unsupported missile weapon subtypes. Tests verify the five runes still match the five sockets, logical record totals, new option text, and unchanged root data.

## Eight 3.3 runewords

Mania, Hysteria, Metamorphosis, Ground, Temper, Hearth, Cure, and Bulwark remain unchanged records. Patch 3.3 RotW Ladder is AVAILABLE; patch 3.3 Non-Ladder/Offline are UNAVAILABLE. Patch 3.4 Non-Ladder/Offline are REVIEW because the official 3.4 note does not explicitly confirm those eight recipes are unlocked there. No new items were added.
