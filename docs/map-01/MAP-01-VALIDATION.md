# MAP-01 검증
- 데이터 검사 1/1 통과. 던전 ID, 액트, 출발·도착, 구간 수, 방향, 기준, 신뢰도, 출처, 이미지 파일과 확률 표기를 검사했다.
- TypeScript, ESLint, Webpack 프로덕션 빌드 통과. 신규 페이지를 정적 페이지로 생성했다.
- PC Chrome 1365×900, 모바일 Chrome 에뮬레이션 390×844에서 각각 2/2 통과. 합계 4/4, 4.3초.
- MAP-T01~T07에서 메뉴, 다섯 액트, 네 던전, 방향과 미확인 구간, 빈 액트 안내, 버튼 겹침·가로 넘침을 확인했다. 각 SVG의 HTTP 응답, XML 구문, viewBox, 제목·설명, 출발·목표 표식, 화살표 경로와 실제 이미지 로딩을 확인했다.
- MAP-T08에서 거래소 첫 화면과 룬워드·유니크·세트 도감 진입을 확인했다. 거래 작성이나 데이터 변경은 검사 범위 밖이다.
- 첫 빌드는 .next/server/app/sets 생성 권한 오류가 발생했고, 필요한 권한으로 같은 명령을 재실행해 성공했다. 기본 브라우저 테스트 포트 4173에서 연결에 실패해 전용 포트 43178에서 이번 빌드로 검증했다.
