# MAP-01 길찾기 규칙 조사
대상 게임은 D2R RotW 3.4다. 로컬 추출 자료 D:/06.dia/MOD-01-A-Analysis/R1-evidence/game-files/vfs-2/data/global/excel/levels.txt에서 층 식별자와 웨이포인트를 대조했다. 지하 묘지 2층(35), 억류지 2층(101), 성채 2층(129)의 Waypoint 값은 각각 8, 26, 38이다. 이 표는 출구 타일의 회전 규칙까지 입증하지 않는다.

| 구간 | 기준과 우선 방향 | 판정 |
|---|---|---|
| 탑 지하 1→2, 2→3, 3→4, 4→5 | 각 층 입구 타일에서 나가는 방향 기준 왼쪽 | COMMUNITY_RULE |
| 지하 묘지 2→3 | 웨이포인트 타일 기준 오른쪽 | COMMUNITY_RULE |
| 지하 묘지 3→4 | 미탐색 통로 확인 | UNVERIFIED |
| 증오의 억류지 2→3 | 웨이포인트 타일 기준 왼쪽 | COMMUNITY_RULE |
| 세계석 성채 2→3 | 웨이포인트 타일 기준 오른쪽 | COMMUNITY_RULE |
| 성채 3→파괴의 왕좌 | 미탐색 통로 확인 | UNVERIFIED |

우선 방향은 출구 타일에 진입하는 방향을 가리킨다. 계단 좌표나 최단 거리를 예측할 수 없다. 보스층에서는 계단 탐색을 마치고 보스 방으로 이동한다. 왕좌에서는 웨이브를 마친 후 보관실로 들어간다.

[층별 방향표](https://diablo2.io/forums/map-reading-t3490.html)와 [D2R 타일 판독 시연](https://www.youtube.com/watch?v=iaAmrldC3c4)을 참고했다. 시연의 해당 구간은 탑 8:34, 묘지 23:16, 억류지 44:20, 성채 52:01이다. 네 가지 우선 방향에 대해 확인한 자료 간 충돌은 발견되지 않았다. RotW 3.4에서 출구 방향을 직접 재현한 근거는 확보하지 못해 VERIFIED로 판정한 방향은 없다.
