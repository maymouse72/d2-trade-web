# RW-BASE-03 — 룬워드 추천 베이스 UI 보고서

## 변경 내용

- `RunewordCatalog.tsx`의 각 룬워드 상세 토글에 추천 베이스 구역을 룬워드 옵션 앞에 추가했습니다.
- 베이스명에 `(NO)`, `(EX)`, `(EL)` 등급을 표시하고, 클래스 전용 장비 표기·추천 이유·`맨땅·육성`/`최종 장비`/`용병` 목적을 제공합니다.
- 룬워드별 장비가 다르면 검·방패·성기사 방패·폴암 등으로 분리해 표시합니다. 예를 들어 Spirit sword와 Spirit shield는 각각 검과 방패 후보를 표시합니다.
- Variant를 선택한 뒤 그 Variant의 장비 유형과 소켓 수로 후보를 걸러냅니다. 원본 `data.json`과 Variant 정의는 수정하지 않았습니다.
- 기존 룬 조합, 옵션, 검색·필터·정렬·페이지 표시를 보존했습니다.

## 스타일 및 반응형

- 기존 다크 테마와 금색 포인트를 사용하고 추천 후보는 카드 안에서 두 열로 나열합니다.
- 화면 폭 650px 이하에서는 후보를 한 열로 바꿉니다. 긴 이름은 줄바꿈됩니다.
- 룬워드 102개 상세를 펼치는 PC 테스트와 모바일 390×844 테스트에서 가로 넘침이 없었습니다.

## 브라우저 결과

- Playwright: 데스크톱 3개 도감 및 모바일 390×844 3개 도감, 총 6/6 통과.
- 룬워드 데스크톱 테스트에서 102개 레코드의 추천 영역을 모두 열어 표시를 확인했습니다.
- 검색·소켓 필터·장비 종류 필터와 옵션 정보 표시가 테스트에서 정상 동작했습니다.
- 세 도감의 브라우저 콘솔 오류 및 페이지 예외: 0건.
