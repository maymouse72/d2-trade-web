## 현황

- JSON 룬워드 상세 항목: **102개**.
- 명칭과 장비 슬롯을 합쳐 본 공식 레시피: **99개**. 영혼, 인내, 불사조는 슬롯별로 나뉘어 도감에 각각 표시됩니다.
- 내부 패치·게임 모드 Variant가 있는 항목: **9개**. 제작 베이스 안내는 기존 Variant 판정/옵션을 덮어쓰지 않고 현재 장비 유형과 소켓 수를 입력으로 사용해야 합니다.
- 기존 베이스 아이템 정규화 자료: **없음**. IAS 무기 카탈로그는 build 3.3의 공격 애니메이션 데이터이며, 방어구·방패·정확한 소켓 제한·베이스 등급을 포함하지 않아 재사용하지 않습니다.
- 룬워드 필터는 현재 장비 유형·소켓·요구 레벨·룬·문자열을 기준으로 동작합니다. 추천 정보는 원본 및 검색 인덱스와 분리해 상세 UI에 추가합니다.

## 구현 및 데이터 현황

1. 게임 베이스 이름/등급/게임 장비 분류/최대 가능 소켓을 별도 62개 후보 카탈로그로 둡니다. 전체 게임의 베이스 아이템 목록을 복사하지 않고 룬워드 추천에 쓰는 선정 후보만 담았습니다.
2. 룬워드 장비 분류를 문자열 부분 일치가 아닌 명시적인 장비 계층 매핑으로 정규화합니다. 클럽·해머·메이스, 근접·미사일, 클래스 전용 방패와 악마술사 마법서를 각각 구분합니다.
3. 일부 대표 룬워드에 명시적 베이스 우선순위를 두고, 나머지는 장비 분류/소켓/요구 레벨 및 장착 가능 정보로 생성합니다. 목적(맨땅·육성/최종 장비/용병)과 짧은 이유를 함께 표시합니다.
4. 자동 검증은 현재 장비/소켓과 모든 저장된 Variant 장비/소켓을 대조합니다. 최대 소켓은 해당 베이스가 소켓을 가질 수 있는 상한으로만 사용하고, 아이템 레벨·라주크 보상 결과를 단정하지 않습니다.
5. `data.json`, Variant 원본, 필터, PWA, 거래소 및 IAS 코드는 수정하지 않았습니다.

## 자료 및 한계

- 3.4.95032 게임 테이블 기반의 룬워드/베이스 비교자료와 Blizzard 3.4 패치 노트, Blizzard의 룬워드 규칙 설명을 교차 확인합니다.
- 현재 로컬에 확인 가능한 D2R 추출 무기 자료는 build 3.3입니다. 따라서 3.4 신규 아이템의 세부 베이스 정보는 이 파일을 근거로 추정하지 않고, 3.4 게임 데이터가 명시된 자료에서 개별 확인합니다.
- 추천 이유는 베이스의 등급, 장비 계열, 용병 장착 가능 여부 등 확인 가능한 특성에 한정합니다. 빌드·공속 계산을 전제하는 무기 선택 조언은 추가하지 않습니다.
- 대표 추천의 우선순위는 별도 JSON에 기록했습니다. 전체 후보를 실전 효율, 요구치, 획득 난이도로 완전 순위화한 것은 아닙니다. 수동 게임 내 제작 검증은 별도 수행하지 않았습니다.
