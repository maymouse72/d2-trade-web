# RW-BASE-06-4 — 드루이드 펠트 검증 보고서

## 결과

- 원본 룬워드 레시피를 변경하지 않고 드루이드 펠트 15종을 카탈로그에 추가했습니다: 일반 5종, 익셉셔널 5종, 엘리트 5종.
- 이름, 등급, 드루이드 전용 분류, 요구치, 내구도, 자동 기술 가능 여부, 소켓 상한과 아이템 레벨 구간을 기록했습니다.
- 탈태(Metamorphosis, 룬 순서 Io·Cham·Fal)는 3소켓 드루이드 펠트 및 일반 투구에 제작 가능하도록 원본 데이터와 대조했습니다.
- 실전 후보는 Wolf Head (NO)와 Blood Spirit (EL)입니다. 두 후보 모두 드루이드 자동 기술을 살릴 수 있고, 3소켓 제작은 아이템 레벨 26 이상에서 가능합니다. Blood Spirit은 힘 86 요구치를 표시합니다.
- 이전 REVIEW 2건은 제거 판정하고, 펠트 후보 두 건을 ADD했습니다. 확인되지 않은 옵션을 새로 만들지 않았습니다.

## 근거 및 한계

기준은 D2R 게임 테이블 build 3.4.95032이며, 데이터 페이지는 각 페이지의 게임 테이블 출처를 공개합니다. [소켓 생성 규칙](https://d2r.org/mechanics/sockets), [Wolf Head](https://d2r.org/data/items/wolf-head), [Blood Spirit](https://d2r.org/data/items/blood-spirit), [Metamorphosis](https://d2r.org/runewords/metamorphosis).

게임 클라이언트에서 직접 제작하는 플레이 테스트는 수행하지 않았습니다. 검증은 게임 데이터 출처 대조, 구조 검사, 자동 테스트 및 로컬 브라우저 화면 확인으로 진행했습니다.
