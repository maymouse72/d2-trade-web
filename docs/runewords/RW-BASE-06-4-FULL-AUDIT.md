# RW-BASE-06-4 — 전체 추천 감사

## 범위 및 결과

- 102/102 룬워드에 검토된 추천 데이터가 연결되어 있습니다.
- 공개 추천은 기존 기준 205건에서 최종 204건으로 조정됐습니다. 어둠의 Spiked Club 및 파멸의 Legendary Mallet은 제작 불가로 제외했고, 파멸의 Thunder Maul 후보를 추가했습니다. 탈태는 펠트 2개를 추가했습니다. 일부 이전 후보는 이미 검토된 데이터에 포함되어 있어 최종 수는 단순히 변경 행의 합으로 계산하지 않았습니다.
- 기존 398개 링크는 모두 판정 기록에 남아 있습니다. 추가 판정 행을 포함해 총 416행이며, 상태 합계는 REVISE 192, REMOVE 210, ADD 14, REVIEW 0입니다.
- `pending-review.json`은 비어 있으며 룬워드 원본 레시피와 옵션 JSON은 수정하지 않았습니다.

## 자동 구조 감사

추천 검증은 204개 공개 연결에서 존재하지 않는 베이스, 허용되지 않는 장비 유형, 부족한 소켓 상한, 직업·용병 제한, 아이템 레벨 조건 누락, 비어 있거나 중복된 설명을 검사합니다. 수정 후 룬워드 베이스 테스트 16/16, 아이템 회귀 테스트 13/13, PC·모바일 브라우저 테스트 6/6이 통과했습니다.

룬워드 옵션을 근거로 Passion, Harmony, Beast를 추가 검토했고, Socketing과 base item 데이터는 D2R build 3.4.95032 출처와 대조했습니다. 참고: [전체 룬워드 게임 데이터](https://d2r.org/runewords), [소켓 규칙](https://d2r.org/mechanics/sockets), [Beast](https://d2r.org/runewords/beast), [Harmony](https://d2r.org/runewords/harmony), [Passion](https://d2r.org/runewords/passion).

## 제한

모든 추천의 게임 내 체감 성능을 직접 측정하지 않았습니다. 자동·브라우저 검증은 제작 호환성과 화면 표시를 확인하며, 빌드의 실제 효율은 별도 게임 플레이 검증 대상입니다. 목록에 없는 개별 베이스의 표기 정보까지 게임 내에서 실측했다고 주장하지 않습니다.
