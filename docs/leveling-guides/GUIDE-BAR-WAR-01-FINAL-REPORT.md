# GUIDE-BAR-WAR-01 최종 보고

## 판정: PASS

야만용사·악마술사 공략과 직업별 대표 이미지 8종을 직업별 목록 및 페이지에 추가했습니다. 7개 직업에 공통 순간이동 충전 지팡이 팁을 적용했고 원소술사는 제외했습니다. 스킬 표에서 확인된 오류와 선행 경로를 바로잡았습니다.

## 결과 요약

- 콘텐츠: 두 직업의 난이도별 진행, 능력치, 장비, 기술표, 보스·면역 대응, FCR, FAQ 및 체크리스트 추가.
- 포인트: 야만용사 28/43/96, 악마술사 43/96 스냅샷과 선행 조건·레벨 상한 통과.
- 데이터 기준: 악마술사 3.4.95032 게임 테이블과 Blizzard 패치 노트를 대조. 로컬 D2R 설치본은 3.3.93847이라 실제 로컬 게임 화면에서 3.4 플레이 검증은 하지 않았음.
- 이미지: 투명도가 유지된 8개 WebP, 총 580,208바이트. PC·390×844에서 모두 로드되고 잘림·가로 넘침 없음.
- 공통 팁: 원소술사 제외, 나머지 7개에 표시됨.
- 자동 검사: 단위 15/15, 브라우저 14/14, TypeScript PASS, ESLint PASS, Webpack 빌드 PASS.
- 회귀: 기존 6개 직업 문서, 목록 검색, 룬워드 딥링크, 체크리스트, PC·모바일 화면 PASS.

최종 운영 커밋·Vercel ID·READY·도메인 확인은 배포 후 이 보고서의 배포 결과 항목에 기록합니다.
