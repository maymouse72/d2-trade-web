# GUIDE-BAR-WAR-01 공통 순간이동 지팡이 팁

## 표시 정책

- 공통 컴포넌트: `app/game-info/leveling-guides/TeleportStaffTip.tsx`
- 직업 공략 데이터에 문구를 복제하지 않고 1개 컴포넌트에서 공통 본문을 공유합니다.
- 성기사·강령술사·암살자·아마존·드루이드·야만용사·악마술사에 노출하며 원소술사는 제외합니다.
- 악마술사에는 칼날 이동이 자체 이동 기술이며 충전 지팡이는 필수가 아니라는 추가 문장을 표시합니다.

## 확인된 내용과 안내

- 액트 3 오르무스의 상점에서 순간이동 충전 옵션이 붙은 지팡이를 찾을 수 있습니다.
- 캐릭터 19~23레벨은 해당 지팡이의 요구 레벨을 아직 충족하지 못해 붉게 보이는 물품을 찾기 쉬운 구매 창입니다. 24레벨부터는 이 색상 차이가 사라져 구분 편의가 낮아집니다.
- 일반적인 `+ 순간이동` 직업 기술 보너스와 충전 옵션을 구분하라고 안내합니다.
- 충전 수량은 유한하며 소진 시 수리 비용이 들 수 있다고 알립니다.

구매 시기 및 상점 노출 팁은 Blizzard 문서가 아니라 커뮤니티 상점 가이드에 기반한 편의 팁입니다. 게시 문구는 “구매할 수 있습니다”, “찾기 쉽습니다”로 표현해 확정 드롭처럼 과장하지 않았습니다.

## 검증 결과

브라우저 테스트에서 원소술사는 팁이 0개, 다른 7개 직업은 모두 1개 표시되는지 확인했습니다. 각 팁 안에 “오르무스”와 “레벨 19~23”이 있고 모바일과 데스크톱에서 가로 넘침이 없는 것을 통과했습니다.
