# GUIDE-BAR-WAR-01 테스트 결과

## 자동 검사

| 명령 | 결과 |
|---|---|
| `npm run test:guides` | PASS — 15/15 |
| `npx tsc --noEmit` | PASS |
| `npm run lint` | PASS |
| `npm run build:webpack` | PASS — Next.js 16.4.3, Webpack, 정적 생성 21/21 |

첫 기본 샌드박스 빌드는 `.next` 하위 폴더 생성에서 EPERM이 발생했습니다. 프로젝트 ACL 확인 및 단순 Node `mkdir` 재현은 성공했지만, Next build 프로세스의 `.next` 생성은 샌드박스 안에서만 실패했습니다. 승인된 동일 프로젝트 경로의 실행 권한으로 재실행해 Webpack 빌드가 정상 완료됐습니다. 빌드 산출물은 로컬 `.next`에만 생성되며 저장소에 포함하지 않습니다.

## PC·모바일 브라우저 검사

검사 대상은 Playwright의 `desktop-chrome` (1365×900) 및 `mobile-chrome-390x844` 프로젝트입니다.

- `npm run test:guides:browser`: **14/14 통과** (7개 시나리오를 각 뷰포트에서 실행)
- 8개 직업 페이지 및 목록 검색·라우팅
- 8개 이미지 로딩·비율과 세로 크기
- 원소술사 팁 제외, 나머지 7개 직업 공통 팁
- 야만용사·악마술사 페이지의 기술·포인트 합계·목차
- 룬워드 딥링크, 체크리스트, 가로 넘침 검사
- 페이지 예외 및 콘솔 오류 검사: 신규 오류 없음

최초 브라우저 실행은 사용 중인 4173 포트의 이전 프로덕션 서버를 재사용해 오래된 페이지를 검사했습니다. 별도 포트 4175에 현재 빌드를 띄워 전체 검사를 다시 실행했고 최종 결과는 PASS입니다.

## 결과 해석

빌드와 테스트는 구현과 표시 동작을 검증합니다. 헬 바알까지 실제 캐릭터를 직접 플레이해 클리어한 성능 테스트는 아니며, Warlock 원고에 면역 대응 한계를 명시했습니다.
