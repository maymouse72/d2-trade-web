# GUIDE-BAR-WAR-01 원고 검토

## 검토 범위

- 야만용사: 이중 타격·광분에서 전장의 함성 싱어 바바로 전환하는 솔로 육성안
- 악마술사: 독기 계열에서 심연을 중심으로 성장하고 종말을 보조로 추가하는 혼합안
- 검토 기준: 게임 기술 요구 레벨·선행 기술·시너지, 3.4 공식 변경 내역, 사용자가 제공한 원고

## 야만용사 수정 사항

- 전장의 함성은 물리 피해로 표기했습니다. 따라서 원고에 섞여 있던 “마법 면역 대응”을 “물리 면역 대응”으로 고치고, 광폭화·용병·우회를 안내합니다.
- 광폭화는 집중의 선행 기술이므로 표와 자동 검증 데이터에 강격 → 기절 → 집중 → 광폭화 경로를 넣었습니다.
- 전장의 함성 선행 조건인 전투의 함성 및 전투 지시를 반영했습니다. 시너지는 포효·도발·전투의 함성입니다.
- 레벨 85 표에 아이템 발견을 넣기 위해 물약 찾기와 선행 투자를 반영했습니다.
- 영혼 검 쌍수를 필수 장비로 단정하지 않고 베이스·착용 조건을 직접 확인하도록 문구를 완화했습니다.
- 인간 형태 야만용사 FCR 표와 저항·생명력을 해치지 않는 63% 목표를 안내합니다.

## 악마술사 수정 사항

- 기술 이름, 요구 레벨 및 선행 경로를 게임 데이터 기준으로 정리했습니다. 공중 부양 숙련(1) → 메아리치는 타격(12) → 칼날 이동(18) 경로를 목표표에 포함했습니다.
- 독기 볼트(1) → 독기 사슬(12) → 향상된 엔트로피(24) → 심연(30) 경로와 화염 파도·인장 기술을 거치는 종말(30) 경로를 표기했습니다.
- 기술 표기는 Blizzard 한국어 패치 노트에 나온 “독기 볼트”, “독기 사슬”, “심연”을 우선하고 데이터 키가 되는 영문명도 병기했습니다. 종말 및 다른 명칭은 게임 한국어 현지화 표기를 따랐습니다.
- 칼날 이동에 선행 2포인트가 필요함을 반영하고, 이를 원하지 않는 경우 주력 기술과 포인트 경쟁이 있음을 안내합니다.
- 종말은 화염 피해, 심연은 마법 피해로 안내합니다. 혼합 피해가 모든 면역을 해결한다고 과장하지 않고 이중 면역은 용병·우회 대상임을 명시했습니다.
- 악마술사 전용 마법서와 양손 무기 규칙은 Blizzard 직업 소개에 근거해 설명하되, 특정 룬워드를 마법서 베이스에 만들 수 있다고 추정하지 않았습니다.
- 악마술사 FCR 표(9/18/30/48/75/125%)는 3.4.95032 게임 애니메이션 자료에서 계산된 프레임 표로 표시했습니다. 시전 지연 기술의 재사용 지연은 FCR로 없어지지 않는다고 덧붙였습니다.

## 버전·출처 판단

- Blizzard의 3.4 노트에는 아이템 조정 및 버그 수정이 기재되어 있고 이 두 직업의 기술 트리 재조정은 기재되어 있지 않습니다. 악마술사 독기 계열의 주요 밸런스 조정은 Blizzard 한국어 3.2 노트에 기록되어 있습니다.
- 악마술사 세부 스킬표는 2026-11-13 추출 빌드 3.4.95032의 게임 테이블을 공개한 D2R.ORG 자료와 대조했습니다. 이 자료는 Blizzard 공식 문서는 아니지만 출처·추출 빌드를 공개합니다.
- 확인 가능한 로컬 D2R 설치본은 3.3.93847입니다. 로컬 실행본에서 3.4 게임 화면을 직접 플레이해 검증한 것은 아닙니다. 게시물과 테스트는 3.4.95032 데이터 표를 기준으로 합니다.
- 스킬 표 자동 검증은 포인트 합계, 레벨 랭크 상한, 선행 조건, 레벨 29/40/85 진행을 검사합니다. 이 검증만으로 전체 헬 플레이를 보증하지 않으며 원고도 이 한계를 안내합니다.
