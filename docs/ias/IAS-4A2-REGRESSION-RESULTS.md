# IAS-4-A-2 기존 서비스 회귀 결과

## 운영 Production 읽기 전용 점검
운영 URL에서 다음 페이지가 모두 HTTP 200을 반환했다.

- `/` 거래 목록: 실제 카드 4개가 렌더링됨
- `/trade/18` 매물 상세: 아이템 옵션, 방 정보 렌더링; 실시간 댓글 0건 상태 정상 표시
- `/trade/16` 매물 상세: 기존 실시간 댓글 1건(“팔렸나요?”)을 정상 조회
- `/game-info`, `/game-info/experience`: 경험치 정보 및 게임 정보 경로 정상
- `/game-info/ias-calculator`: 새 기술 선택 UI와 계산기 정상
- `/runewords`, `/uniques`, `/sets`: 도감 경로 정상

거래 상세와 댓글은 읽기만 수행했으며 매물·댓글을 등록하지 않았다. 상세 페이지에는 Supabase GoTrueClient 인스턴스 중복 경고가 한 건 표시됐다. 로그 자체가 오류가 아니라고 명시하고, IAS 계산기 운영 콘솔에는 오류/경고가 없었다. 이 경고는 이 배포 변경과 무관한 기존 인증 초기화 경고로 보고 기록한다.

## 메뉴 및 브라우저
운영 브라우저에서 헤더 거래소/도감/게임 정보 메뉴, 게임 정보 하위 경험치/공속 메뉴를 확인했다. `IAS-4A2-BROWSER-TEST-RESULTS.md`에 있는 로컬 PC와 모바일 확인도 통과했다.

## 판정
회귀 점검 PASS. 운영 DB·계정·댓글은 변경하지 않았다.
