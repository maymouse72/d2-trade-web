# IAS-3-B-2 계산 근거 계보

## 계산기 간 계보

```text
Amazon Basin / Phrozen Keep references ── cited contributions ──> Warren1001 IAS Calculator
                                                                    ├──> Icy Veins credits Warren1001
                                                                    └──> diablo2.io explicitly forks Warren v1.1.3

Tradia local D2R data + AnimData frame parameters ──> Tradia calculator
D2R.org AnimData-derived tables + stated Amazon Basin validation ──> Paladin A1 breakpoint table
Dongaroo ──> lineage not established in this review
```

이 도식은 사이트가 공개한 설명을 정리한 것이다. 코드가 공유되지 않았다고 단정하는 의미가 아니다. Icy Veins, diablo2.io, Warren 결과는 동일 계보 가능성이 있으므로 독립 표본으로 세지 않는다. Tradia 및 D2R.org가 A1의 별도 교차 확인에는 도움이 되지만, 현재 조사에서 Paladin A2를 식별하는 데이터 레코드와 StartingFrame 근거는 입증하지 못했다.

## A2 증거 판정

- A2 별도 선택 및 애니메이션 식별: 공개 후보 중 검증 가능한 명시 증거 없음.
- 성기사 A2별 AnimData 레코드/StartingFrame: 직접 확인 가능한 자료 미확보.
- 게임 빌드와 프레임 정의가 함께 고정된 독립 A2 결과: 미확보.
- 따라서 Crystal Sword, Phase Blade, War Hammer A2 상태는 각각 UNVERIFIED, A2 Golden 행은 0으로 유지.
