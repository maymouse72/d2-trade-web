# IAS-4A-1 — A1 프레임 산식과 경계 검증

## 계산 경로

이번 단계는 새 엔진이나 산식을 구현하지 않았다. 기존 검증된 Paladin A1 기준값을 세 기술의 범위 한정 후보로 대조했다.

1. 로컬 `skills.txt`: `anim=A1`, `seqtrans=A1`, `UseAttackRate=1`.
2. 무기 코드로 WSM 적용: Crystal Sword 0, Phase Blade -30, War Hammer +20.
3. 기존 A1 IAS 모델에서 무기·장비 IAS를 적용하여 공격 애니메이션 프레임 구간 선택.
4. 완전 애니메이션 프레임을 정수로 비교. 실제 게임 입력 지연, 서버 틱, 액션 프레임과 혼동하지 않는다.

공개 D2R.org 계산 안내가 기술하는 기본 EIAS 형태는 `floor(120 × IAS / (120 + IAS)) - WSM + skill speed`; EIAS clamp는 -85..75, 프레임 산출은 무기 클래스별 A1 데이터에 따른다. 이 검증에서 스킬별 speed 항은 별도 가산하지 않는다. 세 원본 레코드 및 해당 기술 문서에서 추가 IAS 속도 보정이 발견되지 않았기 때문이다. `UseAttackRate=1`의 상세 엔진 의미를 실행 파일 역공학으로 검증한 것은 아니다.

## 경계 비교

아래 기대치는 기존 project Golden Dataset과 Tradia UI에서 교차 확인한 A1 프레임이다. 세 스킬의 외부 도구 선택이 동일한 그룹이므로 수치 비교는 그룹 공통 A1 비교로 기록한다.

| 무기 | WSM | 경계 IAS → 프레임 |
|---|---:|---|
| Crystal Sword | 0 | 0→14, 8→14, 9→13, 10→13, 151→9, 152→8, 200→8 |
| Phase Blade | -30 | 0→11, 7→11, 8→10, 23→10, 24→9, 25→9, 53→9, 54→8, 200→8 |
| War Hammer | +20 | 0→18, 167→10, 168→9, 169→9, 316→9, 317→8 |

War Hammer IAS 318은 무기 데이터셋의 상한 317을 넘어 입력 대상에서 제외된다. 이는 계산 프레임이 318에서 어떠한가를 뜻하지 않는다.

전체 breakpoint와 Golden 파일 출처는 `IAS-4A1-REFERENCE-COMPARISON.csv`, 각 201/201/318행 기존 JSON에서 확인한다. 기존 A1 데이터 합계 720행은 읽기 전용으로 유지했다.

## 해석 한계

브레이크포인트 행과 Tradia 표시 결과는 UI에서 읽은 값이며 별도의 in-game frame capture는 없다. 커뮤니티 사이트의 계산 구현 계보가 완전히 독립인지 확인되지 않았으므로 두 출처 수를 독립적인 원본 엔진 실험처럼 합산하지 않는다. 이 문서는 기존 A1 산식을 재승인하거나 전체 지원 정책을 바꾸지 않으며 IAS-4-A-2 구현 진입을 위한 범위 제한 근거다.
