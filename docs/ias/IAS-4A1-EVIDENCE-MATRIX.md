## 출처의 성격

- E1: 설치된 D2R 3.3.93847 CASC에서 로컬로 추출한 표. 파일 SHA-256은 `IAS-4A1-DATA-DISCOVERY.md` 참고.
- E2: 프로젝트 기존 Paladin A1 Golden Dataset 201 + 201 + 318 = 720행 및 IAS-3B AnimData/COF 검증 자료. 이 작업에서 변경하지 않음.
- E3: D2R.org는 동일 게임 빌드 데이터 및 기술별 설명을 공개하고, Tradia에서 같은 세 기술을 하나의 선택지로 제공한다. 입력 경계값이 기존 A1 값과 일치한다. 출처의 코드 계보 독립성은 완전 감사하지 않았다.
- E4: 실제 게임 프레임 캡처/입력 녹화 없음.

결론의 적용 범위는 Paladin 인간형 한손 단일 무기 일반 A1 한 번 공격이다. A2나 별도 공격 시퀀스의 결론으로 확대하지 않는다. 이후 IAS-4-A-2에서 기술별 Golden 벡터와 사용자 UI를 추가하되, 이 보고서 자체는 제품 지원 활성화가 아니다.
