# IAS-2B 테스트 결과

## 자동 검사

- IAS 엔진 및 UI 모델: `npm run test:ias` — 16/16 통과. IAS-2A 기존 12개와 UI 모델 신규 4개를 포함한다.
- Golden Dataset: 201/201 엔진 계산값 일치.
- UI 모델 경계: 0, 8/9, 18/19, 31/32, 40, 53/54, 85/86, 151/152, 200 확인.
- 입력: 빈 값, 문자, 음수, 소수, 공백/과학 표기, 201 이상 거부.
- 미지원: A2, Phase Blade, War Hammer, Amazon에서 지원 상태가 아니며 결과 필드 없음.
- TypeScript: `npx tsc --noEmit` 통과.
- ESLint: `npm run lint` 통과.

## 브라우저 UI 검사

- 데스크톱: 로컬 Next 개발 서버에서 페이지와 계산 조건/결과/표 렌더링을 확인했다.
- 모바일: 390×844 뷰포트에서 입력과 결과가 세로로 정렬되고 브레이크포인트 표를 가로로 잘라내지 않는지 확인했다.
- Webpack 프로덕션 산출물: IAS 0/40/54/152, IAS 201 오류, A2/Phase Blade/War Hammer/Amazon 미지원 처리를 확인했다.
- 게임 정보 메뉴: 경험치 정보 및 공속 계산기 링크가 존재하고 계산기 경로로 연결된다.
- 기존 경험치 페이지: 레벨 45 기본 추천 및 표가 렌더링된다.
- 운영 변경 전: 거래 목록, 거래 상세 `/trade/16`, 댓글 조회를 읽기 전용으로 확인했다. 제안 입력/알림 상태는 변경하지 않았다.

## 미완료 또는 환경 의존 검사

- Production 배포 후 동일 IAS 시나리오, 기존 경로, 도메인 연결 및 모바일을 다시 확인한다.
- 오프라인 캐시 동작은 수행하지 않았다. 배포 전 거래 상세에서는 기존 앱 업데이트 안내와 푸시 준비 중 안내가 노출됐다. 이번 변경은 PWA/Push 파일을 수정하지 않는다.
- Turbopack은 이번 두 시도에서 진행 출력이 없었고 단독 재시도도 약 1분 넘게 정체되어 종료했다. IAS-2A에서도 2분 이상 정체가 있었다. 요청된 Webpack 검증은 별도 실행에서 통과했다. Vercel 빌드 결과는 배포 로그에서 별도로 확인한다.
