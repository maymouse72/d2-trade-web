# IAS-3-A 용어 및 화면 개선

작성일: 2026-11-01

| 기존/기술 용어 | 사용자 화면 용어 | 설명 |
|---|---|---|
| IAS 입력 | 공격 속도 증가 합계 (IAS) | 무기와 다른 장비에 붙은 IAS를 합산해 입력하도록 안내 |
| A1 | 기본 공격 동작 1 (A1) | 기술 식별자를 한글 설명과 함께 제공 |
| Breakpoint | 공속 기준값 (IAS), 공속 기준(브레이크포인트) | 프레임이 감소하는 기준을 설명 팝오버로 제공 |
| Animation frames | 공격 동작 전체 길이 | 표시값이 전체 애니메이션 프레임임을 명시 |
| IAS total | 공격 속도 증가 수치 구간 | 해당 프레임 구간에 적용되는 정수 IAS 범위를 표기 |

무기별 검증 범위를 입력 아래에 표시하며, ±1/±10 버튼으로 값을 조정할 수 있습니다. 크리스탈 소드, 페이즈 블레이드, 워 해머의 데이터 표를 선택에 맞춰 바꾸고 검증되지 않은 직업/동작 조합에는 결과와 표를 숨깁니다. 안내문은 A1이 모든 공격에 적용되는 동작이라는 오해, 전체 프레임을 타격 판정 시점으로 해석하는 오해를 줄입니다.
