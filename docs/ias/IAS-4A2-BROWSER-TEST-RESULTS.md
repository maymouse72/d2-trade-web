# IAS-4-A-2 브라우저 검증 결과

## Computer Use 주소 제한 원인과 해결
Windows Chrome 창을 화면/창 제목에서 판독하는 Computer Use 경로는 현재 탭 URL을 충분히 신뢰성 있게 식별하지 못했다. 이는 사이트 코드나 Vercel 설정이 아니라 해당 네이티브 창 주소 판별 경로의 한계였다. Codex 브라우저 도구의 탭 메타데이터에서 URL을 직접 읽거나, 명시된 로컬 URL을 Codex 내장 브라우저에 지정해 검증하는 방식으로 해결했다. 로컬 Next 서버는 격리된 네트워크에서 loopback 바인딩이 거부되어 승인된 로컬 서버 실행 권한이 필요했다. Chrome 보안 설정, 안전 제어, URL 신뢰 정책은 변경하거나 우회하지 않았다.

## PC
Webpack Production build 로컬 앱을 Chrome에서 확인했다. Crystal Sword의 기본 결과/기준표, 지원되는 세 기술 선택, 무기 변경, 입력 상한 및 잘못된 값에 대한 기존 결과 제거, A2 계산 차단을 확인했다. War Hammer IAS 316은 9프레임과 다음 기준 317, 317은 8프레임, 318을 직접 입력했을 때 값은 상한 317로 제한됐다. Zeal/Smite 비활성화와 브레이크포인트 표도 확인했다. 브라우저 콘솔 로그: `[]`.

## 모바일 390×844
같은 Production build에서 고정 390×844 뷰포트 프레임으로 확인했다. 실제 페이지 viewport 390×844, 문서/본문 폭 375px, 수평 스크롤 최대 0px였다. 무기·기술 선택, 숫자 입력, 증감 버튼, 결과·브레이크포인트 표 확인. 표는 자체 스크롤 영역 안에 있고 페이지 자체 가로 넘침은 없었다. 모바일 콘솔 로그: `[]`.
