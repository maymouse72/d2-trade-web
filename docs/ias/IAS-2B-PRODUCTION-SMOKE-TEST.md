# IAS-2B 운영 스모크 테스트

## 배포 전 기준

- Production 도메인의 거래소 홈과 거래 목록이 표시됐다.
- 기존 `/game-info/experience`가 레벨 45 추천과 표를 표시했다.
- 거래 카드에서 `/trade/16` 상세로 이동했고 기존 댓글 1건을 읽을 수 있었다.
- Production 도메인은 기존 `d2-trade-web-6e47` 프로젝트 배포에 연결돼 있었다.
- 기존 UI에 앱 업데이트 배너가 나타났다. 거래 상세 알림 영역은 서버 알림 기능이 비활성화됐거나 준비 중이라고 표시했다. 상태 변경은 하지 않았다.

## 배포 후

실제 도메인에서 페이지, IAS 0/40/54/152, 입력 오류/미지원 조합, 메뉴, 경험치, 거래 목록/상세/댓글, 모바일과 PWA 영향 확인 결과를 기록한다. 거래 등록, 댓글 작성, 로그인/계정 변경, 알림 구독 변경은 하지 않는다.
