# IAS-4-E Fanaticism Golden Report

- New separate file: `lib/ias/data/fanaticism-golden.json`.
- Dataset scope: 19 verified weapon/skill combinations × 60 effective levels.
- Breakpoint rows: 4,364 transition rows; each row stores weapon code, skill, level, Fanaticism SIAS, IAS threshold, EIAS and expected frames.
- Dataset is generated by `scripts/generate-fanaticism-golden.mjs`; regeneration is deterministic.
- Evidence is formula-derived from the extracted D2R `dm34` parameters and independently cross-checked D2R EIAS / Paladin animation formulas. It is not an in-game measurement and does not modify existing Golden inputs.
- Existing A1, skill-derived, Zeal and Smite Golden files are unchanged. The 52-test IAS suite includes a check of the separate Fanaticism transition vectors and OFF parity.
- Important limitation: this Fanaticism dataset is derived from the same explicit formula and frame equations used by the implementation; it is not an independent empirical frame capture. That distinction is recorded rather than presenting it as separate in-game truth.
